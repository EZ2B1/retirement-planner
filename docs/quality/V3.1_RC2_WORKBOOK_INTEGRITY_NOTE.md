# Version 3.1 RC2 Workbook Integrity Note

## Status

`Retirement_Planner_v3.1_RC2.xlsx` is the approved workbook baseline for the
Version 3.1 design review.

## Correction from RC1

Microsoft Excel reported an invalid overlapping merged-cell definition on the
`Conversion Tax Funding` worksheet.

The conflicting ranges were:

- `A1:G2`
- `A1:J2`

RC2 removes the conflict and retains the intended title merge:

- `A1:J2`

## Scope of change

- No financial calculation logic changed.
- No formulas or input values were intentionally changed.
- No worksheets were added or removed.
- The correction is limited to workbook package integrity and presentation.

## Validation completed

- Workbook opened without an Excel recovery message.
- All 36 worksheets remained present.
- No additional overlapping merge ranges were identified.
- No obvious `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?`, or `#N/A` strings were found.

## Repository role

RC2 is retained under `workbooks/reference/` as a controlled baseline artifact.
Future workbook generation code must create only the intended `A1:J2` merge on
the `Conversion Tax Funding` worksheet.
